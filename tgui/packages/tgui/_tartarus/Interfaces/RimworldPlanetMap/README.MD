# Planetary Map

Copyright (c) 2026 Fenysha. All rights reserved.

This directory contains the original planetary map implementation created by
Fenysha.

The implementation includes, but is not limited to:

- Planetary map generation
- Procedural terrain generation
- Climate and biome generation
- Planetary surface rendering
- Planetary shaders
- Camera and navigation systems
- Planetary objects and map data
- Supporting generation and rendering utilities
